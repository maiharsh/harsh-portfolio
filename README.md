# Harshvardhan Portfolio

Next.js portfolio app located in [`harshvardhan-Portfolio`](./harshvardhan-Portfolio).

## Deploy on Vercel

1. Import this repository in [Vercel](https://vercel.com/new).
2. Set **Root Directory** to `harshvardhan-Portfolio` (required — the app is not at the repo root).
3. Framework preset: **Next.js** (auto-detected).
4. Build command: `npm run build` (default).
5. Install command: `npm install` (default).
6. Optional: add environment variable `NEXT_PUBLIC_SITE_URL` with your production URL (e.g. `https://your-domain.vercel.app`) for correct SEO metadata, sitemap, and Open Graph URLs. If omitted, Vercel uses `VERCEL_URL` automatically.

## Local development

```bash
cd harshvardhan-Portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
